설비·자료 기준

1. 대상과 문서 범위 사용자가 지정한 ‘2번 적산기’로 등록했습니다. 여기서 적산기는 수치 적산계가 아니라 주조기에서 나온 INGOT를 자동으로 쌓는 AUTO STACKING MACHINE입니다. 원본 PDF 1개 20쪽과 한글 문서 2개를 원형 보존했습니다. PDF 전체, HWP 본문과 추출 그림 12개를 검토했습니다. HWP 열람본은 검색 가능한 텍스트·그림 추출본이며 원본 페이지나 표 배치의 재현은 아닙니다. 2. 구성과 흐름 자료상 1차 콘베어·INGUIDE·1/2차 스토퍼 → 4P/7P CATCH → 이재기(대차) → X-LIFT → 3차 콘베어 → 계량대·CAS 계량 인터페이스로 구성됩니다. 수동/자동·원위치·단수·적재량·반재/만재 조작 및 상태 표시가 있습니다. 이 흐름은 문서 설명의 요약이며 현장 시퀀스 시험 결과가 아닙니다. 3. 서로 다른 자료 시점 PDF 1쪽 표제는 광명금속(주), 2004년 10월 15일, ASM-04입니다. 파일명 ‘220721’은 문서 내용의 개정 확인 근거가 아닙니다. 사용 설명서는 (주)세진메탈, 2006년 2월 표제입니다. 시운전 요령은 세진메탈 연속주조기(2006)와 두인 자동적산기(2015)가 한 파일에 섞여 있습니다. 어느 자료가 현재 설비에 적용되는지 현장 확인 전입니다. 4. 용량·정격의 경계 사용 설명서 개요에는 300kg·600kg·1TON, 조작·자동 운전 설명에는 500kg·1000kg이 나타납니다. 두 표기를 보존하며 현장 정격으로 하나를 선택하지 않았습니다. 본문 전원 표기는 3상 380V 60Hz, 제어 AC220V, PLC 제어 AC110V, 입력 DC24V, 출력 AC220V입니다. 이는 설명서 표기이고 현재 명판·전원 측정값이 아닙니다. 공압 단위가 혼재된 원문 수치는 현행 설정값으로 변환하지 않았습니다. PDF의 DC24V 출력 릴레이 회로와 AC220V 부하 회로도 구분합니다. 통합 공정 배치도는 아직 제공되지 않았습니다.
