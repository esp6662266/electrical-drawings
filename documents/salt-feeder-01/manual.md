# 1번 솔트 투입기

전기도면 SALT-01 · v1.1.0 · 2026-10-20 · 로컬 검토본

9개 원본 PDF, 총12페이지를 근거로 정리했습니다. 아성 스프링피더(2017년 도면)와 원창 계량·진공이송(2012년 기계도면 등)을 서로 다른 자료 계통으로 보존합니다. 한 도면의 모터·I/O·정격을 다른 계통에 배정하지 않습니다.

도면 기반 매뉴얼 작성 완료(미확정 항목 포함). 원본9파일·12페이지 보존. 실제 PLC 프로젝트·래더·현재 CPU·현장 배선·운전·복구 검증은 미수행입니다.

## 설비·자료 기준

1. 설비 식별과 자료 범위
사용자가 제공한 폴더를 ‘1번 솔트 투입기’ 자료로 등록했습니다. 이번 식별은 사용자 지정 기준이며, 현재 명판·실물 대조를 수행한 것은 아닙니다. 원본9개, PDF 총12페이지를 각각 보존했습니다.

2. 아성 스프링피더 계통
기계도면에는 SPRING FEEDER #1/#2와 호퍼가 나타납니다. 외형도 작성일은2017-01-21, 호퍼도는2017-01-10, 전기도면01/02는2017-08-08로 표시됩니다. 호퍼 본문에는 ‘HOPPER 2.8m³ - 1SET / STS304 2.0T’, 표제에는 ‘SILO 3M³’가 함께 있어 두 표기를 보존합니다. 정격 저장량/허용 적재량은 별도 확인 전입니다.

3. 원창 계량·진공이송 계통
기계도면에는 인렛 호퍼, 스크루, Vacuum Conveying System, LIW Feeding System, WCA-610 Feeder, 플랫폼스케일과 조작반이 나타납니다. 기계도면의 작성일은2012-03-21입니다. 전기도면4페이지는 조작반 외형, POWER DIAGRAM NO1, A-WEIGHT CONTROL, INTERPOSITION으로 구성됩니다.

4. 자료를 합치는 기준
아성의 M1/M2와 원창의 VACUUM/SCREW/FEEDER 모터를 동일 대상으로 묶지 않았습니다. FEEDING #1/#2는 도면 내부 명칭으로, 사용자의 ‘1번 솔트 투입기’라는 관리번호와 다른 층위입니다.

5. 부품 자료
삼양 V135와 Siemens 외형도는 참고 규격입니다. 장착 명판·축·플랜지·감속비 확인 없이 교체품이나 호환품으로 확정하지 않습니다. 수기메모가 있는 원창 기계도면은 별도 원본으로 남겼으며 그 메모를 현재 운전 설정값으로 채택하지 않았습니다.

## I/O·단자·조작부

1. 구분 원칙
I/O·HMI 탭은 PLC 주소 목록과 동일하지 않습니다. 이번 자료의 전기 접점·원창 계량제어기 단자·신호 선번을 ‘계통’과 ‘근거 구분’으로 나누었습니다. 실제 PLC 주소가 확인된 항목은0건입니다.

2. 아성 전기도면02의 접점·코일
S1 E-STOP, LV1/LV2, R1/R2, T1/T2, M, TH1, INV1, BZ 표기를 원문 기준으로 정리했습니다. 이 기호는 릴레이·접점·코일 명칭이며 PLC 메모리 주소가 아닙니다. LV1/LV2의 현재 정상극성·센서 모델·동작 높이와 T1/T2 설정시간은 제공자료로 확정하지 않습니다.

3. 원창 계량제어기 단자
세진메탈 전기도면 PDF3쪽은 WMC-175EFK의 CPU I/O 24Pin, D/A1, A/D1, A/D2를 표시합니다. Start/Stop 접점, RUN·제어이상·Refill·운전중·Low Low·High High·유량이상 표시와 외부 연결 선번을 구분했습니다. 단자10의 P011 등은 도면 선번으로 취급하며 DR-40S 주소로 변환하지 않았습니다.

4. 아날로그·계량 경로
D/A1 CH1 Feeder CONTROL은 도면상4~20mA이며 KBSI 인터페이스와 SCR 제어 회로로 이어집니다. A/D1은 로드셀 브리지의 Sig/SE/EX·실드 배선, A/D2는 세진메탈 패널의 S.SET1+/S.SET2- 입력입니다. 실제 영점·스팬·부호·배선·단선 검증은 미수행입니다.

5. 조작부
원창 반면도에는 MAN/AUTO, AUTO START/STOP, S-FEEDER, HOPPER LOW, AIR KNOCKER, BUZZER RESET, REFILL, VACUUM, PUMP, WCA FEEDER 조작부가 나타납니다. 이는 패널 부품표이며 HMI 태그나 내부 PLC 주소는 확보하지 못했습니다.

## 제어 구조와 PLC 확인 범위

1. 아성 계통의 정적 회로 해석
전기도면01에서3상440V 60Hz가 MCC1 ABN33(20A)를 거쳐 FEEDING1 전자접촉기/열동보호 분기, FEEDING2 인버터 분기, TR-01 제어변압기 분기로 나뉩니다. 전기도면02의 RL/TL 제어회로에는 S1, FEEDING1/2 조작 접점, LV1/LV2, R1/R2, T1/T2, M과 BZ가 표시됩니다.

R2 접점은 별도 박스의 M01-GND1 ‘FEEDING2 INVERTER START’에 연결됩니다. 이는 인버터 접점 기동 경로이며 PLC 출력이 아닙니다. M·R2 관련 코일/표시 회로의 공통 하부 경로에는 TH1 접점이 있습니다. 정확한 접점 상태·재기동 조건은 원본 확대 대조와 실물 확인 전입니다.

S1은 RL 제어 레일에 나타납니다. 이 도면만으로 동력측 완전 차단, 이중 안전회로, 안전등급 또는 현재 안전기능 적합성을 확인했다고 표시하지 않습니다. T1/T2의 설정시간과 현장 운전 순서를 임의로 작성하지 않았습니다.

2. 원창 계통의 제어 구성
POWER DIAGRAM NO1은 VACUUM MOTOR7.5HP×4P, SCREW MOTOR1HP×4P 인버터, 440/220V 2kVA 변압기, 별도 계량/진공패널 전원 분기, AC220V/DC24V1.2A 전원공급기와 DR-40S 표시를 포함합니다. 같은 NFB-1 표기가 여러 분기에 반복되므로 태그만으로 회로를 합치지 않습니다.

계량제어기 WMC-175EFK의 신호는 KBSI 인터페이스 및 KBIC-240D SCR 제어기와 피더 스크루/교반 모터 쪽으로 연결됩니다. 이 DC/SCR 경로를3상 스크루 인버터 분기와 동일 회로로 합치지 않습니다.

3. 외부 인터페이스
INTERPOSITION은 원창 패널과 세진메탈측의 접점/4~20mA 연결을 제시합니다. OUT의 RY4C-C100/D100 ‘AUTO READE’ 표기와 IN의 D100/D101, SET+/SET-는 원문대로 남깁니다. 세진메탈측 단자번호 칸은 비어 있으며 D100 등을 PLC 데이터레지스터로 확정하지 않습니다.

4. PLC 정리의 한계
DR-40S 도면 표시는 확보했으나 프로그램·CPU 정보·I/O 할당·내부 주소·래더·타이머 설정을 받지 못했습니다. 호출 구조와 래더 탭을 가상의 프로그램으로 채우지 않았습니다.

## 전기 전달 경로

A1. 아성 FEEDING1 동력
3상440V → MCC1 ABN33(20A) → MC-12 표기 전자접촉기 → THR1 MT-32 → M1 FEEDING1(440V/2HP)입니다. 기호/정격은 전기도면01 기준이며 보호설정·현재 장착 정격은 확인 전입니다.

A2. 아성 FEEDING2 동력·기동
동일 전원에서 인버터로 분기되어 M2 FEEDING2(440V/2HP)로 갑니다. 전기도면02에서 R2 접점이 M01-GND1 인버터 기동 회로에 그려져 있습니다. 인버터 모델·현재 파라미터는 미확정입니다.

A3. 아성 제어전원
TR-01 440/220V100VA → CB2P2A → RL/TL 제어전원입니다. 접지 PE와 제어전원의 중성/공통선을 혼동하지 않습니다. 전기도면02의 TH1/INV1과 부저 경로는 별도 확인 항목으로 관리합니다.

W1. 원창 VACUUM 동력
3상440V → 해당 NFB 분기 → MC-1 GMC-40 → EOCR(3A-30A 표기) → VACUUM MOTOR7.5HP×4P입니다. 접점 제어 상세/현재 EOCR 설정은 미확보입니다.

W2. 원창 SCREW 동력
3상440V → 별도5A 표기 분기 → SV008IG5A-4U 표기 인버터 → SCREW MOTOR1HP×4P입니다. RY42 접점과 속도설정 가변저항1k의 연결이 표시되며 현재 설정값은 확정하지 않습니다.

W3. 계량·보조전원
440/220V2kVA 변압기 → CP-1/CP-2의 계량패널·진공패널 전원과 CP-3의 RL/TL, 노이즈필터, DC24V 전원공급기로 나뉩니다. 도면에서 기기 전원과 신호전원을 구분하되 실배선은 미확정입니다.

W4. 피더 SCR·로드셀
계량제어기 아날로그 출력 → KBSI → KBIC-240D → FEEDER SCREW MOTOR, 별도 KBIC-240D → FEEDER AGITATION MOTOR가 표시됩니다. A/D1 로드셀 Sig/SE/EX·SH, A/D2 S.SET 입력은 원본 단자표 기준으로 정리합니다.

세진메탈 전기도면의 부품표(MUT-2200EFK)와 회로도(WMC-175EFK), 아성 FEEDER2 기계도1HP와 전기도2HP가 서로 다릅니다. 어느 하나를 현재 장착품으로 선택하지 않았습니다.

## 알람·보호·복구 기준

1. 아성 보호·부저
전기도면02에는 TH1 및 INV1 접점과 BZ/부저 선택 접점이 나타납니다. TH1 트립 계통, 인버터 이상 계통을 분리하여 확인할 항목으로 작성했습니다. THR1(전기도01)과 TH1(전기도02)의 실제 대응, 정상 접점 상태와 부저 리셋 방식은 현장 대조 전입니다.

2. 레벨 및 공급 상태
LV1/LV2와 관련 표시/릴레이는 상·하레벨 동작 경로의 도면 근거입니다. 센서 반전, 우회, 시간값 변경을 복구 방법으로 제시하지 않습니다. 투입이 안 된다는 증상만으로 레벨센서 불량을 확정하지 않습니다.

3. 원창 계량제어기 표시
제어이상·Refill·운전중·Low Low·High High·유량이상 표시가 CPU 단자표에 있습니다. 각 표시의 설정치, 래치, 타이머, PLC 수신주소는 미확보입니다. 패널의 BUZZER RESET 버튼 존재와 실제 보호해제/재시작 허용은 서로 다릅니다.

4. 복구 기록 기준
첫 증상·첫 표시·발생시각, 확인한 원본/실물 위치, 원인 후보와 배제 근거, 실제 수행 조치, 조치 후 관찰, 미확정 사항을 수리 기록에 남깁니다. 본 문서 작성으로 고장 복구·안전기능 검증·운전 확인을 완료했다고 표시하지 않습니다.

## 증상별 점검

1. 점검 전 자료와 계통 식별
대상 조작반·모터·호퍼가 아성인지 원창인지 명판·도면번호로 먼저 대조합니다. 계통을 구분하지 못하면 다른 도면의 태그나 설정값을 가져오지 않습니다. 현장 점검은 현장 절차에 따라 전원 차단·잔류 에너지 해소를 확인한 후 수행하고, 운전 중 측정·강제출력·안전회로 우회는 이 문서의 작업 범위에 포함하지 않습니다.

2. 공급모터가 기동하지 않을 때
아성은 MCC1, 제어변압기/CB, S1, TH1, FEEDING 접점, 레벨·R1/R2/T1/T2, M 및 인버터 접점 경로의 도면 위치를 순서대로 대조합니다. 원창은 VACUUM/SCREW/피더 SCR을 별개 모터계통으로 구분합니다. 공통 원인이라고 가정하지 않습니다.

3. 회전하지만 솔트가 이송되지 않을 때
호퍼 잔량·배출구 막힘·이물·스프링/스크루 파손·기계적 결합을 현장 확인 항목으로 남깁니다. 원창은 진공이송부 배관·인렛호퍼·스크루·계량부를 별개 구간으로 나누어 증상을 기록합니다. 이는 점검 후보이며 실제 결함 판정이 아닙니다.

4. 계량·공급량이 불안정할 때
원창 로드셀 A/D1 Sig/SE/EX·실드와 계량부 기계간섭, D/A1 출력·KBSI·SCR 경로, 외부 S.SET 입력을 각자 확인 대상으로 분리합니다. 프로그램·파라미터·명판이 없는 상태에서 영점/스팬·인버터 파라미터를 추정하여 변경하지 않습니다.

5. 교체 전 확인
실제 모터 정격, 축·키·플랜지, 감속비, 브레이크 유무, 회전방향, 장착 치수를 대조합니다. 삼양0.75kW 도면, Siemens2HP 외형도와 각 장비도면 정격을 서로 대체 근거로 사용하지 않습니다.

6. 기록

## 증상별 점검

### 전체 공급부가 반응하지 않음

대상반 식별 → MCC1/제어전원 분기 → TR-01/CB/RL·TL → S1·TH1·조작접점의 도면 위치 대조

미확정: 실제 통전·단자 측정·안전기능은 미수행

근거: 전기도면-1.pdf · PDF 1쪽

### FEEDING1만 기동 안 됨

M1의 MC-12/THR1 경로와 제어M, FEEDING1·레벨·R1/T1/T2 관계를 각각 대조

미확정: 레벨센서 불량·타이머 값으로 단정하지 않음

근거: 전기도면-2.pdf · PDF 1쪽

### FEEDING2만 기동 안 됨

M2 동력 인버터 분기, R2 접점·M01/GND1 연결을 분리 대조

미확정: 인버터 모델/이상코드·실배선 미확정

근거: 전기도면-2.pdf · PDF 1쪽

### 레벨에 따라 이송이 불안정

LV1/LV2 실물 대응·부착높이·기계막힘과 T1/T2 설정 근거 수집

미확정: 정상극성·시간·운전순서 미확정; 우회/설정변경 지시 없음

근거: 전기도면-2.pdf · PDF 1쪽

### 부저가 울리거나 정지가 반복

TH1과 INV1 경로를 나누고 최초 표시·시각·대상모터 기록

미확정: 실제 고장/복구 조치 기록 없음

근거: 전기도면-2.pdf · PDF 1쪽

### 진공 이송이 안 됨

VACUUM모터/MC-1/EOCR 동력 분기와 배관·인렛호퍼·필터 관찰 구간 분리

미확정: 진공도·전류·막힘·누설 실제 결과 없음

근거: 세진메탈 전기도면.pdf · PDF 2쪽

### SCREW만 기동 안 됨

인버터 분기·RY42 접점·속도설정 회로와기계결합 대조

미확정: 1HP 모터 현재 명판·파라미터 미확보

근거: 세진메탈 전기도면.pdf · PDF 2쪽

### 계량 표시·공급량이 흔들림

A/D1 로드셀/실드·기계간섭, D/A1→KBSI→SCR, 외부S.SET을 각자 구분

미확정: 실제영점/스팬/배선/전류 미확정

근거: 세진메탈 전기도면.pdf · PDF 3쪽

### 피더 스크루·교반이 동작 안 됨

KBIC-240D 두 분기, RY43/RY40 등 접점·DC모터 배선의 원본 위치 대조

미확정: SCREW MOTOR 인버터와다른 계통; 프로그램 근거 미확보

근거: 세진메탈 전기도면.pdf · PDF 3쪽

### 상위/외부 연동이 안 됨

INTERPOSITION OUT/IN, C100/D100/D101 및 SET+/SET-를단자대단자로 식별

미확정: 세진메탈측 단자번호 공란·신호방향 실물미확정
